- 🧪 **5 個完整實戰 Lab / 5 Hands-on Labs** — 可直接運行的 Python 腳本 + 互動測試

- 🔧 **完整工具鏈 / Complete Toolchain** — 訓練器、評估指標、預處理、可視化

## 🚀 快速開始 | 快速开始

### 安裝 | Installation

```bash
# Clone
git clone https://github.com/chanxaviersy/nlp-ml-knowledge-base.git
cd nlp-ml-knowledge-base

# 安裝依賴
pip install -r requirements.txt

# NLTK 數據
python -c "import nltk; nltk.download('punkt'); nltk.download('punkt_tab')"

# spaCy 模型（可選）
python -m spacy download en_core_web_sm
python -m spacy download zh_core_web_sm
```

### 跑 Lab | Run a Lab

```bash
# Lab 01: 情感分析（無需 GPU）
cd docs/08-labs/01-sentiment-analysis
python lab.py

# Lab 03: BERT 微調（建議 GPU）
cd docs/08-labs/03-transformer-sentiment
python lab.py

# Lab 05: RAG 問答
cd docs/08-labs/05-rag-qa-system
python lab.py
```

### 統一數據載入 | Unified Data Loading

```python
from datasets.loader import load_sentiment_data, load_ner_data, load_rag_documents

# 自動在線下載，失敗 fallback 到本地
train_df, test_df = load_sentiment_data()

# NER (BIO 格式)
train_sents, train_tags, test_sents, test_tags = load_ner_data()
```
